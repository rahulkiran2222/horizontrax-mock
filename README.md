## 🔴 The Problem

### The Indian Placement Crisis — By the Numbers

```
╔══════════════════════════════════════════════════════════════════╗
║                                                                  ║
║   1.5 Million    engineering graduates every year in India       ║
║                                                                  ║
║   Only ~30%      are considered employable                       ║
║                  (NASSCOM / Aspiring Minds Report)               ║
║                                                                  ║
║   ~70%           fail at the aptitude/technical screening round  ║
║                  before they even reach the interview            ║
║                                                                  ║
║   The #1 reason? Lack of realistic, timed practice              ║
║                  with actionable feedback                        ║
║                                                                  ║
╚══════════════════════════════════════════════════════════════════╝
```

### What Students Currently Do

| Approach | Problem |
|----------|---------|
| **Free YouTube / PDFs** | No structured practice, no timer, no feedback |
| **Paid platforms (₹5,000–₹15,000/year)** | Expensive for Tier 2/3 college students |
| **Previous year papers** | Static, no analytics, no improvement tracking |
| **College placement cells** | Conduct 1–2 mock tests, no personalized feedback |
| **Studying in groups** | No way to measure individual weaknesses |

### The Core Gap

```
What students GET:         Score: 45/100. Better luck next time.

What students NEED:        Score: 45/100.
                           → You're weak in "Time & Work" (2/8 correct)
                           → You're spending 3.2 min/question on Logical Reasoning
                             (optimal is 1.5 min)
                           → Your accuracy drops 40% in the last 15 minutes
                             (fatigue pattern detected)
                           → Focus on: Quantitative → Time & Work → Level 2 problems
                           → Estimated improvement if addressed: +12 marks
```

**That gap — between a score and a diagnosis — is what HorizonTrax fills.**

Exam integrity without a proctor.

```
TAB-SWITCH DETECTION SYSTEM:

  Student switches tab
       │
       ▼
  ┌─────────────┐
  │  Strike 1   │ → ⚠️ WARNING: "You switched tabs.
  │             │      This is your 1st warning.
  │             │      2 more and your test will be suspended."
  └──────┬──────┘
         │ switches again
         ▼
  ┌─────────────┐
  │  Strike 2   │ → ⚠️ FINAL WARNING: "This is your LAST warning.
  │             │      One more tab switch and your exam
  │             │      will be terminated and marked as CHEATING."
  └──────┬──────┘
         │ switches again
         ▼
  ┌─────────────┐
  │  Strike 3   │ → 🔴 SUSPENDED: "Your exam has been terminated.
  │  GAME OVER  │      Reason: Suspected cheating (3 tab switches)
  │             │      This attempt is recorded."
  └─────────────┘

  ┌────────────────────────────────────────────┐
  │  Technical Implementation:                 │
  │  • visibilitychange event listener         │
  │  • blur/focus detection                    │
  │  • Strike counter persisted in state       │
  │  • Cannot resume after suspension          │
  │  • Logged in analytics for review          │
  └────────────────────────────────────────────┘
```

| Technology | Why We Chose It |
|-----------|----------------|
| **Next.js** | SSR for SEO, API routes eliminate separate backend, fast page loads, React ecosystem |
| **Self-Hosted** | Full control over data, no vendor lock-in, cost-effective at scale |
| **Cloudflare Pages** | Free beta hosting, global CDN, automatic HTTPS |
| **Custom AI (no library)** | Zero dependency, runs client-side, no API latency, works offline |
| **Self-Created Questions** | Quality control, aligned with actual placement patterns, no copyright issues |

## ⚡ Getting Started

### For Students (Just Use It!)

```
1. Visit https://horizontrax-mock.pages.dev
2. Select a mock test
3. Start practicing!
```

### For Developers (Run Locally)

#### Prerequisites

- **Node.js** 18+ ([nodejs.org](https://nodejs.org/))
- **npm** or **yarn** or **pnpm**
- **Git**

#### Installation

```bash
# Clone the repository
git clone https://github.com/your-username/horizontrax-mock.git
cd horizontrax-mock

# Install dependencies
npm install

# Run development server
npm run dev

# Open in browser
# → http://localhost:3000
```

#### Build for Production

```bash
# Create optimized production build
npm run build

# Start production server
npm start

# Or export static site
npm run export
```

#### Environment Variables (if any)

```env
# .env.local
NEXT_PUBLIC_SITE_URL=https://horizontrax.com
NEXT_PUBLIC_ANALYTICS_ENABLED=true
```
